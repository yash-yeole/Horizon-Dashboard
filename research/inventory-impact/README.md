# inventory_impact — EIA crude inventory → Brent impact framework

Event-study framework assessing how the weekly **EIA crude inventory** release moves
**Brent**. Converted from the original `rough_work/` notebooks (01–08) into runnable
`.py` modules. Full narrative handoff: [`00_HANDOFF.md`](00_HANDOFF.md);
scoring: [`09_SCORING_REPORT.md`](09_SCORING_REPORT.md).

**Headline:** the inventory print is not a reliable Brent driver in the current
war-premium regime → call is **NEUTRAL** (validated 3 ways).

## Pipeline (run in order — each reads/writes `../cache/`)

| Module | Step | Role |
|---|---|---|
| `s01_event_study.py` | 0 | Build the event table; raw surprise↔reaction correlation (+0.12, weak) |
| `s02_macro_abnormal.py` | 1 | Market-model betas → abnormal return → market-controlled inventory beta |
| `s03_regime_call.py` | 2 | Regime call — war premium dominates inventory |
| `s04_validation.py` | 3 | Out-of-sample validation (3 ways) — negative OOS skill |
| `s05_news_layer.py` | 4 | News-tone layer |
| `s06_api_surprise.py` | 5 | API (vs EIA) surprise layer |
| `s07_reasoning.py` | 6 | Reasoning / synthesis layer |
| `s08_wti_forecast.py` | 8 | WTI forecast + product reactions |

### Supporting WTI analyses (fed step 8)
`predict_inventory.py` · `product_reactions.py` · `wti_consensus_analysis.py` ·
`wti_longhistory.py` (desk-grade: real published consensus, 390 releases) ·
`wti_reaction_full.py`

## Data / environment
- Consensus history: `../WTI_consensus.csv` (EIA crude, actual/forecast/previous).
- Actuals via EIA API (key in `backend/.env` as `HORIZON_EIA_API_KEY`); prices via
  `Regime/data/*.csv` + yfinance gap-fill.
- Run with the research venv `C:/Users/<user>/.venvs/energy` (see `00_HANDOFF.md` §3
  and `requirements-research.txt`).

> These modules replace the executed notebooks; the `../cache/` parquets are
> regenerated by running `s01_event_study.py` first.
